Chapter 2

Open it & read the prompt

Meet it
Open a terminal
  • macOS: ⌘ + Space, type “Terminal”, press Enter. (iTerm2 is a popular free upgrade.)
  • Linux: Ctrl + Alt + T on most distributions.
  • Windows: install WSL: open PowerShell as administrator, run wsl --install, restart, then open “Ubuntu” from the Start menu. That gives you a real Linux terminal, so every command in this guide works. More in Appendix · Windows & WSL
The shell
SnapThe program inside the window that reads your commands is the shell. On a Mac it's zsh; on Linux and WSL it's usually bash. For everything in this guide, they behave the same.
~ ❯ echo $SHELL
/bin/zsh
Anatomy of a prompt

The prompt is the shell saying “I'm ready, your turn.” What it shows depends on your setup. The prompts in this guide come from one example setup, zsh with Prezto (see Chapter 10). Yours will look different, and that's fine.

adayour username
@macbookthe computer
~/thesiscurrent folder
maingit branch (if any)
❯“type here”
ls▌your command

Yours might show % or $ instead of ❯, or nothing but the folder. In instructions online, $ at the start of a line means “type what follows”, so don't type the $ itself.

Chapter 3

Anatomy of a command

Meet it
SnapAlmost every command has the same shape: what to do, then how, then on what. Separated by spaces.
lscommand
“list files”
-l -aoptions (flags)
long format, all files
~/Downloadsargument
which folder
Flags come in two sizes 
~ ❯ ls -l -a      # short flags
~ ❯ ls -la        # same, combined
~ ❯ ls --all      # long flag, same as -a
Forgot a flag? Ask 
~ ❯ man ls          # the manual (q to quit)
~ ❯ python --help   # most programs have this
~ ❯ git help commit
Spaces matter 
~ ❯ cd My Thesis
cd: string not in pwd: My
~ ❯ cd "My Thesis"   # quotes keep it together

The shell splits on spaces. Easiest fix: never use spaces in file and folder names. Use my-thesis or my_thesis.

Chapter 4

Where am I? Paths

Move around
SnapYour files live in a big upside-down tree. The terminal is always standing in one folder: the working directory. Everything you type happens there.
Look & move 
~/thesis ❯ pwd            # print working directory
/Users/ada/thesis
~/thesis ❯ ls             # what's here?
analysis.py  data
~/thesis ❯ cd data        # go into a folder
~/thesis/data ❯ cd ..     # go up one level
~/thesis ❯ cd             # go home (same as cd ~)
~ ❯ cd -                # back to previous folder
Absolute vs relative

Absolute paths start with / (or ~) and work from anywhere:

/Users/ada/thesis/data/raw.csv

Relative paths start from where you are now. From ~/thesis:

data/raw.csv · ./analysis.py · ../Downloads/paper.pdf

. = this folder, .. = the folder above.

The #1 reason scripts “can't find” files
SnapRelative paths in Python are relative to where you started the command, not where the script lives.
# analysis.py contains: open("data/raw.csv")
~/thesis/scripts ❯ python ../analysis.py
FileNotFoundError: 'data/raw.csv'
~/thesis ❯ python analysis.py   ✓ works

Chapter 5

Files & folders

Move around
Make, copy, move, rename 
~/thesis ❯ mkdir results               # new folder
~/thesis ❯ mkdir -p data/raw/2026      # create nested folders at once
~/thesis ❯ touch notes.md              # new empty file
~/thesis ❯ cp notes.md notes-backup.md  # copy
~/thesis ❯ cp -r data data-copy         # copy a whole folder
~/thesis ❯ mv notes.md docs/            # move into a folder
~/thesis ❯ mv draft.py model.py         # rename = move to a new name
~/thesis ❯ ls -lh                       # list with sizes (human-readable)
Deleting 
~/thesis ❯ rm old.csv          # delete a file
~/thesis ❯ rm -r old-results/  # delete a folder
No trash can, no undo. Double-check with ls before you rm.
Bridge to your normal desktop 
~/thesis ❯ open .              # macOS: open this folder in Finder
~/thesis ❯ open paper.pdf      # open a file with its default app
~/thesis ❯ xdg-open .          # Linux
~/thesis ❯ explorer.exe .      # WSL: open in Windows Explorer

Tip: drag a file from Finder into the terminal window to paste its full path.

Chapter 6

Look inside files

Move around
Read without opening an app 
~/thesis ❯ cat notes.md           # print the whole file
~/thesis ❯ less README.md         # scroll through (q quits)
~/thesis ❯ head -n 5 data/raw.csv # first 5 lines
~/thesis ❯ tail -n 20 train.log   # last 20 lines
~/thesis ❯ tail -f train.log      # follow live (Ctrl+C stops)
~/thesis ❯ wc -l data/raw.csv     # count lines

head on a CSV is the fastest way to see its columns, much faster than opening a 2 GB file in Excel.

Edit in the terminal

nano is the friendly one: the shortcuts are listed at the bottom (^O save, ^X exit, where ^ is Ctrl).

~/thesis ❯ nano notes.md

vim is powerful and often the only editor on a server. Worth learning one day (vimtutor teaches it in 30 minutes).

SamHelp! I typed vim and now nothing works and I can't get out!
SnapA rite of passage! Press Esc, then type :q! and Enter. That quits without saving. (:wq saves and quits.)
Chapter 7

Keyboard superpowers

Level up
SnapPros don't type faster, they type less. Learn these keys and the terminal feels ten times quicker.
Tab
Autocomplete. Type cd th + Tab → cd thesis/. Press twice to see all options. If Tab completes nothing, the file isn't there (or you're in the wrong folder).
↑ ↓
History. Scroll through previous commands. No need to retype that long pip install line.
Ctrl+R
Search history. Type part of an old command, e.g. clone, to find it.
Ctrl+C
Stop! Cancels the running program or the half-typed line. Your emergency brake. (It does not copy here!)
Ctrl+L
Clear the screen. Same as typing clear.
Ctrl+A / E
Jump to the start / end of the line.

Copy and paste: ⌘+C / ⌘+V on macOS; Ctrl+Shift+C / V in most Linux and WSL terminals.

Wildcards 
~/thesis ❯ ls *.py            # every .py file
~/thesis ❯ ls data/*.csv
~/thesis ❯ cp results/run_*.json backup/
~/thesis ❯ ls **/*.py         # zsh: in all subfolders

* means “anything”. The shell expands it into the list of matching names before the command runs.

Reuse what you typed 
~ ❯ history | tail    # your last commands
~ ❯ !!                # repeat the last command
~ ❯ cd !$             # reuse last argument
Chain commands 
~ ❯ cd thesis && ls      # 2nd runs only if 1st worked
~ ❯ mkdir out; cd out     # run one after another
Chapter 8

Pipes & redirection

Level up
SnapSmall commands, plumbed together. | sends the output of one command into the next.
~/thesis ❯ cat train.log | grep ERROR | wc -l
3
Useful pipes 
❯ ls | wc -l                 # how many files?
❯ grep -i "accuracy" train.log | tail -3
❯ pip list | grep torch      # is torch installed?
❯ history | grep conda
Send output to a file 
❯ ls > files.txt          # write (overwrites!)
❯ echo "run 2" >> log.txt # append to the end
❯ python train.py > out.log 2>&1

The last one saves normal output and errors (2>&1) to one file, handy for long runs.

Find things 
❯ grep -rn "def train" .    # text inside files
❯ find . -name "*.csv"       # files by name
❯ du -sh data/               # how big is it?

These come back in Issue #2 · Ch. 3 ↗ to explore research code.

Chapter 9

Running programs

Level up
Python from the terminal 
~/thesis ❯ python3 analysis.py      # run a script
~/thesis ❯ python3                  # interactive Python
>>> 2 + 2
4
>>> exit()
~/thesis ❯ jupyter lab              # yes, Jupyter starts here too

Jupyter runs inside that terminal. Close the terminal (or press Ctrl+C) and the notebook server stops.

Where do commands come from?
SnapWhen you type python, the shell searches a list of folders called PATH and runs the first match it finds.
❯ which python3
/opt/homebrew/bin/python3
❯ echo $PATH
/opt/homebrew/bin:/usr/bin:/bin:…

Activating a Python environment simply puts its folder first in PATH. Issue #2 · Ch. 7 ↗

Variables & scripts 
❯ echo $HOME
/Users/ada
❯ export DATA_DIR=~/thesis/data   # for this session
❯ bash scripts/train.sh           # run a shell script
❯ chmod +x scripts/train.sh       # or make it runnable…
❯ ./scripts/train.sh              # …and run it directly
Be careful with sudo (“run as administrator”). Only use it when you know why, and never for pip install.
Chapter 10

Make it yours: a prompt that talks back

Level up
Your config file

Your shell reads a config file every time a terminal opens: ~/.zshrc for zsh, ~/.bashrc for bash. Put your shortcuts there.

# in ~/.zshrc (or ~/.bashrc)
alias ll="ls -lah"
alias gs="git status"
alias act="source .venv/bin/activate"

❯ source ~/.zshrc   # reload without reopening

Files starting with . are hidden. ls -a shows them.

What a configured prompt can tell you
SnapA plain prompt only says where you are. A configured one also tells you what state you're in, before you type anything.
PromptTells you
ada@macbook thesis %Plain zsh: user, computer, folder. That's all.
~/Downloads ❯❯❯Not inside a Git repository: no branch shown.
~/thesis main ❯❯❯Inside a Git repository, on branch main.
~/thesis main ✱ ❯❯❯…with uncommitted changes. Time for git status.
(thesis) ~/thesis try-lr ❯❯❯A Python environment (thesis) is active, and you're on branch try-lr.
~/thesis main ❯❯❯The last command failed (the first arrow turns red).

Why it helps: you notice the wrong branch before committing, the wrong environment before installing, and uncommitted work before switching. Exact symbols and colours depend on the theme you pick.

One example: zsh + Prezto

The prompts in this guide come from the author's own setup: zsh with Prezto, a ready-made zsh configuration (theme: sorin). It adds the Git-aware prompt, smarter Tab completion, colours as you type and suggestions from your history.

# back up your current config first!
❯ cp ~/.zshrc ~/.zshrc.backup
❯ git clone --recursive \
    https://github.com/sorin-ionescu/prezto.git \
    "${ZDOTDIR:-$HOME}/.zprezto"
# then follow the install steps
# in the prezto README

Modules and theme live in ~/.zpreztorc, e.g. 'git', 'syntax-highlighting', 'autosuggestions'. prompt -l lists themes.

Other ways to get there
  • Oh My Zsh: the most popular zsh configuration framework, with hundreds of themes.
  • Starship: one prompt that works the same in zsh, bash and even PowerShell.
  • Plain bash: Git ships a small script, git-prompt.sh, that adds the branch to your bash prompt.

Pick one, or none: all of this is optional. The point is knowing that a prompt can do this.

On Linux or WSL? Get zsh too 
$ sudo apt install zsh
$ chsh -s "$(which zsh)"
# reopen the terminal

One of the few good reasons for sudo. Totally optional: bash works fine for everything in this guide.

Terminal error bestiary

Level up
SnapThe terminal is blunt, not angry. Every message tells you what it didn't like.
Field guide
You seeIt meansTry
zsh: command not found: pyhtonTypo, or the program isn't installed / not in PATH.Check spelling; which python3; activate your environment
no such file or directoryThe path is wrong from where you are.pwd, ls, and use Tab to complete paths
permission denied: ./train.shThe file isn't marked as runnable, or isn't yours.bash train.sh or chmod +x train.sh
zsh: no matches found: .[dev]zsh treats [ ], * and ? as wildcards.Add quotes: pip install ".[dev]"
Weird file called 1.24 appears after pip install numpy<1.24< and > are redirection symbols.Always quote versions: pip install "numpy<1.24"
Prompt changes to dquote> or quote>You opened a quote and never closed it.Ctrl+C and retype the line
Nothing happens, no prompt comes backA program is still running (or waiting for input).Wait, or Ctrl+C to stop it
Stuck in a screen with : or (END) at the bottomYou're in less or man.Press q
Stuck in a screen full of ~ linesYou're in vim.Esc then :q! Enter
